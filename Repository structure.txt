IBM 360 ALD REPOSITORY STRUCTURE

ALD/<original reference folder>/<page and title>.txt
    Reviewed UTF-8 diagrams and printed listings, with their monospaced layout.

notes/<original reference folder>/
    Current source references and review status, significant corrections or
    exceptions, and unresolved questions. Keep notes concise. Intermediate
    snapshots, repeated acceptance chains and agent progress reports are not
    retained in the working repository; use Git for version history.

json/<original reference folder>/<page and title>.json
    Uniform current page models (ibm360-ald-page-v2), including blocks,
    terminals, nets, geometry and CAS control fields. Reviewed CAS source-layout specifications have an
    additional "source layout" suffix. Aggregate tables such as Socket reference
    and ROS words also live in their corresponding reference folders.

csv/<original reference folder>/<table name>.csv
    Machine-readable content tables. ROS words.csv is currently the published
    aggregate table. Empty mirrored folders are retained for future CSV exports.
    Review and provenance CSV files stay in notes.

tools/repository/
    Repository imports and portable integrity verification.
tools/cas/
    Reusable CAS glyph helper.
tools/normalization/
    Shared current-page schema, conversion, validation and transitional reader.
    Current literals/forms preserve source distinctions; no old page copies or
    history sidecars are required.

tools/references/
    Current socket-listing and card-catalogue builders and cross-checks.

tools/card_ald/
    Shared card-data builder, renderer, use audit and layout tools.

tools/reviews/
    Current source-status validation and source-review tools. New reviewed
    changes can be imported without restoring old repository snapshot trees.

ALD, notes, json and csv use the original reference directory names. Collection-
wide conventions and current manifests are at the notes root. Source status.json
binds the current reviewed files to their original scan references.
The working collection remains outside this repository while conversion continues.

CAS GRID CHANGE
The user supplied a 245-column, 102-line CAS grid for AA001 and Q* except QZ.
The rule and source exceptions are in notes/CAS printer grid specification.json
and notes/CAS source row exceptions.txt. Existing CAS content/specification bytes
are preserved while the new layout is compared against the scans. No print is
removed merely to fit a page, and source row identifiers are not renamed.
