CURRENT CANONICAL ALD PAGE DATA, VERSION 3

Read Canonical page format.txt at the repository root for the field definitions,
review/approval rules and mandatory coordinated schema-change procedure.
ALD page schema.json, Canonical vocabulary.json and Format release.json in this
directory define and lock the current format. No unknown live field is accepted.

Use pages.restore_page for a detached, structurally checked editable view.
Use pages.renormalize_page to rebuild both projections after an explicit edit;
validate_current_page replays the semantic projection and rejects disagreement.
All writes/publication require that full validation and canonical serialization.
Readers check schema, vocabulary and the content-bound review digest without
re-normalizing the whole dataset on every catalogue access.

normalize_page accepts canonical notation only. import_legacy_page is the
explicit in-memory importer for historical v2 review copies. legacy_v2.py is
quarantined compatibility code, not an alternate current writer.
build_uniform_pages retains the review object when copying a current document.
check_format.py checks every registered page and rejects unregistered page
models, format aliases, unknown evidence names, stale approvals, duplicate keys,
nonfinite numbers, serialization drift and mismatching JSON/TXT pairs.

No validation grants a new native or electrical review. User approval is explicit
and separate from source transcription review and complete wiring clearance.

printed_literals.py enforces complete numeric-prefixed printed_label strings.
A border K is a decoration, not an inline numeric prefix. Historical split-v3
review copies use the explicit import_review_page API; current read/write gates
stay strict. The editor uses this import for saved copies without rewriting them.
