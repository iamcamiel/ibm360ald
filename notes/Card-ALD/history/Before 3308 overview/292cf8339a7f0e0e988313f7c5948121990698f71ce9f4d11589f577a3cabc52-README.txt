CARD-ALD COMPOSITE PINOUTS

NNNN.TXT USES THE MANUAL-DEFINITION STANDARD SYMBOLS.
NNNN-01.TXT, NNNN-02.TXT, ETC. RETAIN OBSERVED NOTATION VARIANTS.
ALL VARIANTS OF A CARD HAVE IDENTICAL BOX, WIRE AND PIN POSITIONS.
VERTICAL WIRES HAVE ONE CLEAR COLUMN BETWEEN PARALLEL TRACKS.
VERTICAL WIRES LEAVE TWO COLUMNS CLEAR OF BOXES AND PIN LABELS.
POWER CONTACTS ARE LISTED SEPARATELY IN EVERY DRAWING.
ALL CARD AND VARIANT HEADINGS USE ONE SHARED SEVEN-LINE TEMPLATE.

0141: 1 CANONICAL DRAWING AND 66 OBSERVED NOTATION VARIANTS.
4191: 1 CANONICAL DRAWING AND 17 OBSERVED NOTATION VARIANTS.
4633: 1 CANONICAL DRAWING AND 19 OBSERVED NOTATION VARIANTS.
4634: 1 CANONICAL DRAWING AND 18 OBSERVED NOTATION VARIANTS.

4634 G13 AND 4633 G05: POSSIBLY UNUSED; NO CONNECTION OBSERVED.
4633 U55AC: AR FORM IS OBSERVATION-DERIVED AND PROVISIONAL.

VARIANT SOURCES AND CELL DELTAS: NOTES/CARD-ALD/UNIVERSAL.
SEARCHABLE FILE INDEX: CSV/CARD-ALD/NOTATION VARIANTS.CSV.
ORIGINAL DRAWINGS ARE PRESERVED UNDER NOTES/CARD-ALD/HISTORY.

REBUILD FROM THE REPOSITORY DIRECTORY:
    python tools/card_ald/generate_card.py 4191
USE THE SAME SCRIPT FOR 0141, 4191, 4633 OR 4634.
DEFINITIONS: JSON/CARD-ALD/DEFINITIONS/NNNN.JSON.
ONE SHARED RENDERER; NO PER-CARD PYTHON BUILDER IS REQUIRED.

BUILD CANDIDATE DATA FROM THE TRANSCRIPTION DATABASE:
    python tools/card_ald/build_card_data.py 4633
AUDIT ALL RECORDED USES AGAINST THE COMMON DIAGRAM:
    python tools/card_ald/audit_card_uses.py 4633
TRY NEW GRAPH PLACEMENT AND ROUTING PRIVATELY:
    python tools/card_ald/build_card_data.py 4633 --relayout --render
INSTALL TOOLS/CARD_ALD/REQUIREMENTS.TXT BEFORE GRAPH RELAYOUT.

BOXES REMAIN SEVEN CHARACTERS HIGH BUT MAY START ON ANY LINE.
A HORIZONTAL WIRE MAY PASS DIRECTLY BETWEEN TWO BOXES.
SHARED-NET R PORTIONS USE SHORT HANGING LABELS; STANDALONE R KEEPS A BOX.
THREE EXTRA LABEL CELLS ARE RESERVED FOR NOTATION VARIANTS.
INTERCHANGEABLE A/OR INPUTS MAY REORDER WITHOUT CHANGING PIN IDENTITIES.
PLACEMENT AND ROUTING RULES ARE SHARED ACROSS CARD TYPES.
CANDIDATES ARE REVIEWED BEFORE REPLACING PUBLISHED DRAWINGS.
COMMAND DETAILS AND REPORT LOCATIONS: TOOLS/CARD_ALD/README.TXT.
