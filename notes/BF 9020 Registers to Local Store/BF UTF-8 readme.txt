BF UTF-8 TRANSCRIPTIONS

63 BF pages, transcribed from native TIFF scans with visual source review.
View in JuliaMono, disable word wrapping, and allow 245 columns by 103 rows.
The files use UTF-8 without BOM, spaces (no tabs), and one character per cell.
Printed text, wires and symbols are retained; handwriting is omitted.

✲ is the open asterisk. ◺ replaces a pin-border cell. ◇ is a printed
joining diamond; ┼ represents crossing lines without a joining diamond.
Some hanging reference lists use separate ◇─ and └─ glyphs without a
continuous vertical wire. Text hyphens use -; horizontal wires use ─.
Only the user-approved ALD character set is used, with uppercase letters only.
Unresolved print is �. The footer label is P.N.; machine and part-number
values leave exactly one blank cell before the right title-box border.
