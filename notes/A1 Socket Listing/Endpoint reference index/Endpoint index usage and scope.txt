Endpoint reference index, private snapshot, schema 2

The inventory contains 23,298 literal endpoint observations from all 2,307
verified accepted repository TXT pages. Every observed token keeps its spelling,
zero-based grid row/column, parsed physical components, governing reference,
governance method, eligibility flag and model pointers. It is an endpoint index,
not a fresh wire or port-ordinal transcription.

JSON pages is keyed by source_scan_id. Each page stores the current repo-relative
TXT/model paths and SHA256 bindings, original scan identity, accepted export
record, printed page/frame proof, literal_rows and governing_headers once.
An endpoint links its literal_row_evidence to pages[scan_id].literal_rows and
its governing_header_id to pages[scan_id].governing_headers. Model pointer paths
refer to that page's bound JSON model. The CSV repeats page binding fields for
independent tabular use. Matching results refer to the inventory SHA256.

Raw bare A/B/C/E/K/L prefixes are normalized to 02A/02B/02C/02E/02K/02L only
under the saved direct human instructions. Explicit units such as 03B remain
exact; unlisted or damaged units stay unresolved. A final socket T/B may be
ignored only after the socket digits; pin B05 remains B05. A damaged socket
suffix may add a possible competitor but never becomes eligible High evidence.
The policy stores each immutable instruction receipt once; per-token
unit_rule_receipt names the corresponding policy rule.

Supported literal footer headings require printed body/reference context or
the accepted page model; accepted model-only headings also require exact current
TXT cell equality. Header carry is independent per printed column and resets
at intervening headings. Unreadable, unsupported and absent governing headings
are retained. inferred_footer_column_wrap is always ineligible because column
positions alone do not prove reading order. Consumers must use
eligible_exact_match, not merely the presence of governing_full_reference.

A1 matching keeps all physical aliases before reference masks. Readable physical
contradictions remain exact. Compatible damaged physical tokens and unknown or
unsupported governing observations veto High uniqueness. High requires a
verified current A1 board/socket/pin pair and a uniquely compatible supported
literal reference. Portion/card/function questions remain outside this matcher.
Current original question IDs, replies and issued V4 remain unchanged.

Portable command after repository delivery:
python tools/references/build_endpoint_reference_index.py --repository-root . --output endpoint-reference-index-v1

Optional --export-manifest, --issued-manifest, --pending-overlay and
--authority-dir explicitly select portable inputs. Defaults are:
notes/Reviewed export provenance.json
notes/Manual verification/Workbook binding manifest v4.json
notes/Manual verification/Pending inventory after V4.json
notes/A1 Socket Listing/Endpoint reference index
Current Repository records manifest.json and Content data manifest.json verify
each current TXT/model hash. Closed IDs and issued counts are derived on every
run, so later accepted overlays are supported. The builder writes only its
explicit output directory. Five Initial input snapshots preserve the initial
overlay, export, records, content and issued manifest bytes for audit.

No canonical diagram, source scan, issued workbook or prior manifest is changed
by this private build. Native independent evidence and fixtures are saved
separately beside these outputs.
